10. Metodoloji eki

Null kataloğu

  • α_SEM = clip((Var(LP) − E[SE²])/Var(LP), 0, 1); null = 0 (saf ölçüm gürültüsü). Kör nokta: ortak-mod politika gürültüsü SEM'e girmez (§11.3).
  • α_temporal = clip(1 + 2·corr(LP_t, LP_{t+1}), 0, 1); null corr = −0.5 (paylaşılan P_t penceresi). Yalnız ayrık pencereler için geçerli.
  • α = min(α_SEM, α_temporal).
  • ACF lag≥2 null = 0 (tam ayrık pencereler). Hücre-etiketi permütasyonu paylaşılan-pencere artefaktını yakalamaz.
  • top-k overlap null = k/n (hipergeometrik beklenen fraksiyon).
  • Spearman kriter geçerliliği null = 0; p975 hücre permütasyonu ile.
  • lp_reliability teorik gürültü tabanı 0.444; metrik sıfır dönemez.

  • Bootstrap frame atılır; rejim eşiği stage 16/17 (§10.4) tüm koşulara taşındı (kısa koşularda late dilimi ince kalabilir).
